# Walkthrough: Ventana Contenedora Invisible y Selector de APIs de Citas

## Resumen
Se implementaron dos mejoras clave solicitadas por el usuario:
1. **Ocultamiento de la ventana contenedora**: La aplicación ahora se ejecuta como un verdadero widget flotante de escritorio sin marco de ventana de macOS, sin barra de título ni botones de semáforo nativos, y con fondo transparente (`clearColor`), visualizándose únicamente la tarjeta biselada 3D y su sombra sobre el escritorio.
2. **Selector de Proveedores y APIs de Citas (Sugerencia 3)**: Se integró una arquitectura híbrida con selector interactivo en el panel de ajustes, permitiendo elegir entre el catálogo local offline, GitHub CDN (híbrido sincronizable), The Positive API (en vivo en español) y ZenQuotes API (internacional).

---

## Cambios Implementados

### 1. Ventana Transparente y Widget Flotante Puro
- **`macos/Citas-macos/AppDelegate.mm`**:
  - Se configuró la ventana nativa `NSWindow` para eliminar el marco estándar manteniendo la capacidad de recibir foco de teclado:
    - `styleMask`: `NSWindowStyleMaskTitled | NSWindowStyleMaskFullSizeContentView | NSWindowStyleMaskResizable`.
    - `titlebarAppearsTransparent = YES`, `titleVisibility = NSWindowTitleHidden`.
    - `opaque = NO`, `backgroundColor = [NSColor clearColor]`, `hasShadow = NO`.
    - Se ocultaron los botones de semáforo nativos (`NSWindowCloseButton`, `NSWindowMiniaturizeButton`, `NSWindowZoomButton`).
    - Se habilitó `movableByWindowBackground = YES` para permitir mover la ventana suavemente desde el fondo.
    - Se configuró `rootView.layer.backgroundColor = [NSColor clearColor].CGColor`.
- **`App.tsx`**:
  - Se reemplazó el contenedor con fondo plano opaco por un `View` con `backgroundColor: 'transparent'` y `pointerEvents="box-none"`, permitiendo que los clics fuera de la tarjeta pasen directamente al escritorio o a las aplicaciones detrás de la app.

### 2. Capa de Servicios y Selector de APIs de Citas
- **`src/types/quote.ts`**:
  - Se definieron los tipos `QuoteApiSource` (`'local' | 'github-cdn' | 'positive-api' | 'zenquotes'`) y la interfaz `ApiSourceOption`.
- **`src/services/quotesApi.ts`**:
  - Conexión a múltiples fuentes:
    - `local`: Catálogo integrado curado (24 citas), 100% offline.
    - `github-cdn`: Catálogo remoto dinámico en español (54 citas) alojado en GitHub CDN, sincronizable bajo demanda o al inicio.
    - `positive-api`: The Positive API (`https://positive-api.online/phrase/esp`), citas en español con mapeo inteligente de autores célebres.
    - `zenquotes`: ZenQuotes API (`https://zenquotes.io/api/random`), citas universales.
  - Manejo de timeout (`AbortController`) y fallback automático al catálogo local en caso de error o falta de conexión.
- **`src/store/useQuotesStore.ts`**:
  - Estado `apiSource`, `remoteQuotes`, `isLoadingQuote`, `isSyncingRemote`.
  - Acciones `setApiSource`, `nextQuote` (con soporte para llamadas en vivo a APIs), `syncRemoteQuotes` (guarda citas de GitHub CDN en `AsyncStorage`).
  - Persistencia de la fuente activa y del catálogo remoto en `AsyncStorage`.
- **`src/components/SettingsPanel.tsx`**:
  - Nueva sección visual **"FUENTE DE CITAS (API)"**:
    - Opciones seleccionables con estética retro-biselada, badges descriptivos (`Offline`, `CDN`, `API ES`, `API EN`).
    - Botón interactivo de sincronización para GitHub CDN con feedback inmediato (`¡Listo! X citas sincronizadas`).
    - Mensaje orientativo en modos en vivo (`positive-api`, `zenquotes`).
- **`src/components/BeveledWindow.tsx`**:
  - Indicador de estado de carga `⏳` en el botón de actualización al consultar APIs remotas.
  - Badge discreto en la barra de título (`API` / `CDN`) cuando se utiliza una fuente remota.
