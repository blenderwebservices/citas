# Walkthrough: Integración Visual del Panel de Ajustes en el Widget Flotante

## Resumen
Se revisó e implementó la solución definitiva para el botón de ajustes `[ ⚙ ]`. Previamente, los ajustes se intentaban desplegar como un overlay exterior en una capa flotante de la ventana transparente de macOS, lo cual provocaba que quedaran fuera del encuadre visible o sufrieran problemas de dimensionamiento flex en AppKit.

La solución adoptada integra la vista de ajustes (`SettingsContent`) **directamente dentro del propio widget biselado (`BeveledWindow`)**, logrando una respuesta visual instantánea y natural: al hacer clic en `[ ⚙ ]`, la tarjeta misma cambia de modo y muestra las opciones de configuración en su ubicación actual (esquina superior izquierda).

---

## Cambios Realizados

1. **`src/components/SettingsPanel.tsx`**:
   - Se desacopló y exportó el componente `SettingsContent`, que contiene todo el cuerpo interactivo de ajustes:
     - Selector de Proveedor de Citas (Local, GitHub CDN con botón de sincronización, The Positive API, ZenQuotes).
     - Switch de Modo Oscuro.
     - Filtros de categorías.
     - Buscador y filtro de autores.
     - Contador de citas disponibles.
   - Se eliminaron llamadas a `e.stopPropagation()` incompatibles con React Native nativo y se definieron alturas explícitas seguras.

2. **`src/components/BeveledWindow.tsx`**:
   - Se agregó soporte para `isSettingsOpen` y `onCloseSettings`.
   - **Título dinámico**: Muestra `⚙ Ajustes y Fuente` cuando los ajustes están abiertos, o `Citas Célebres` en modo cita.
   - **Controles interactivos**:
     - En modo ajustes, el botón `[ ⚙ ]` se transforma en `[ ← Volver ]` para retornar de inmediato a la cita.
     - Se mantiene el botón `[ ✕ ]` para cerrar el widget.
   - **Marco interior adaptable**: En modo ajustes, el marco biselado interior adquiere altura confortable (`430px`) y aloja el scroll interactivo con todas las opciones.

3. **`App.tsx`**:
   - Se simplificó la jerarquía de vistas pasando el estado `isSettingsOpen` y el callback `onCloseSettings` directamente al `BeveledWindow`.

4. **Nomenclatura del DMG**:
   - Se compiló el paquete con la nueva convención: `dist/Citas-1.0.2026.11.20.1004.dmg` (**7.2 MB**).
