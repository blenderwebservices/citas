# Walkthrough: React Native puro + macOS (.dmg)

## Resumen
Se eliminó **Expo** y **Electron** del proyecto y se migró completamente a **React Native (`0.79.6`) + `react-native-macos` (`0.79.4`)**, compilando una aplicación nativa de macOS (`Citas.app`) con `xcodebuild` y empaquetándola en `dist/Citas-1.0.0.dmg` mediante `hdiutil`.

## Cambios Principales
- **Eliminación de Expo y Electron**:
  - Se removieron las dependencias de Expo (`expo`, `expo-font`, `expo-status-bar`, `@expo/vector-icons`, `@expo-google-fonts/*`, `react-dom`, `react-native-web`) y Electron (`electron`, `electron-builder`, `electron/main.cjs`, `dist-web/`).
- **Proyecto React Native macOS puro**:
  - `package.json`: `react-native@0.79.6`, `react-native-macos@0.79.4`, `@react-native-async-storage/async-storage`, `zustand`, y scripts `macos` y `mac:dmg`.
  - `App.tsx`, `src/components/BeveledWindow.tsx`, `src/components/SettingsPanel.tsx`, `src/components/RestoreWindowButton.tsx`: adaptados a React Native puro usando `PanResponder` + `Animated.ValueXY` para el arrastre fluido dentro de los límites de la ventana, tipografía `Georgia` para citas y símbolos nativos sin dependencias de Expo.
  - `scripts/build-dmg.sh`: script automatizado para compilar `Citas-macOS` en modo Release (`xcodebuild`) y crear `dist/Citas-1.0.0.dmg` con `hdiutil`.

## Verificación
- `pod install --project-directory=macos`: 70 pods instalados correctamente.
- `npm run mac:dmg`: compilación `xcodebuild` (`** BUILD SUCCEEDED **`), `main.jsbundle` embebido en `Citas.app`, y generación de `dist/Citas-1.0.0.dmg`.
- `npx tsc --noEmit`: 0 errores de tipos.
- `npx --yes tsx --test src/utils/__tests__/quoteFilter.test.ts`: **6/6** pruebas aprobadas.
