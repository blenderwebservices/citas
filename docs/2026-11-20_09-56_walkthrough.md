# Walkthrough: Formato de Versión del DMG con Timestamp

## Resumen
Se configuró el script de generación del instalador y las reglas del proyecto para que a partir de ahora cada compilación de `.dmg` genere un archivo con la nomenclatura exacta solicitada:
`Citas-1.0.[año YYYY].[mes MM].[dia DD].[Hora HHMM].dmg`

---

## Cambios Realizados

1. **`scripts/build-dmg.sh`**:
   - Se reemplazó el nombre estático `dist/Citas-1.0.0.dmg` por una variable dinámica:
     ```bash
     TIMESTAMP="$(date +"%Y.%m.%d.%H%M")"
     DMG_NAME="Citas-1.0.${TIMESTAMP}.dmg"
     DMG_PATH="dist/${DMG_NAME}"
     ```
   - Cada ejecución de `npm run mac:dmg` ahora genera el archivo con la estampa de tiempo correspondiente al momento de la compilación.

2. **`AGENTS.md`**:
   - Se registró la nueva regla formal en la sección de lineamientos del proyecto para que todas las sesiones futuras mantengan esta convención.

---

## Verificación

- **Sintaxis Bash**: `bash -n scripts/build-dmg.sh` ejecutado sin errores.
- **Ejemplo generado**:
  - Salida: `Citas-1.0.2026.11.20.0955.dmg`
