# Walkthrough: Ajustes de Configuración (Tema, API y JSON/CSV)

## Resumen
Se amplió el panel de ajustes para incluir las tres nuevas capacidades solicitadas, manteniendo los filtros por categoría y autor, y se recompiló el instalador nativo `.dmg`.

## Cambios Implementados
- **Tema Claro, Oscuro y Sistema**:
  - `src/types/quote.ts`: Tipo `ThemePreference = 'light' | 'dark' | 'system'`.
  - `App.tsx`: Resolución automática mediante `useColorScheme()` cuando `themePreference === 'system'`.
  - `src/components/SettingsPanel.tsx`: Selector segmentado `Claro | Oscuro | Sistema`.
- **Selección de API de citas o Local**:
  - `src/store/useQuotesStore.ts`: Soporte para `quoteSource` (`'local' | 'api'`), `apiEndpoint` configurable (por defecto `https://dummyjson.com/quotes?limit=30`) y `fetchApiQuotes()` con estados de carga y error.
- **Descarga y Carga desde JSON o CSV**:
  - `src/utils/quoteSerializer.ts`: Serialización y parseo para JSON y CSV (con escape RFC 4180, etiquetas separadas por `|` y normalización de payloads de API).
  - `src/components/SettingsPanel.tsx`: Exportación mediante `Share.share` + vista previa seleccionable; importación desde texto pegado o desde URL en modo `Agregar` o `Reemplazar`, más opción para restaurar el catálogo base.
- **Pruebas**:
  - `src/utils/__tests__/quoteSerializer.test.ts`: Pruebas de ida y vuelta JSON/CSV, parseo de API y validación de errores.

## Verificación
- `npx tsc --noEmit`: 0 errores de tipos.
- `npx --yes tsx --test src/utils/__tests__/quoteFilter.test.ts src/utils/__tests__/quoteSerializer.test.ts`: **10/10** pruebas aprobadas.
- `npm run mac:dmg`: `** BUILD SUCCEEDED **` y `dist/Citas-1.0.0.dmg` regenerado.
