# Walkthrough: Resolución de error y generación de DMG para macOS

## Resumen
Se diagnosticaron y corrigieron los errores que impedían compilar la aplicación para macOS y generar el archivo `.dmg`. Tras aplicar las soluciones, la compilación Release con `xcodebuild` finalizó con éxito (`** BUILD SUCCEEDED **`) y se generó el instalador en `dist/Citas-1.0.0.dmg` (6.5 MB).

## Problemas Identificados y Soluciones

1. **Falta de dependencias CocoaPods (`macos/Pods`)**:
   - *Error*: `error: Unable to open base configuration reference file '.../Pods-Citas-macOS.release.xcconfig'`.
   - *Solución*: Se actualizó `scripts/build-dmg.sh` para detectar automáticamente la ausencia de `macos/Pods` y ejecutar `pod install --project-directory=macos` antes de la compilación.

2. **Incompatibilidad de ABI y símbolos Swift en `@react-native-async-storage/async-storage@3.1.1`**:
   - *Error*: Símbolos no resueltos de Swift Concurrency (`Swift.withTaskCancellationHandler(operation:onCancel:isolation:)` y `SharedAsyncStorage.o`) debido a la precompilación de la versión 3.x con Swift 6 GA en contraposición con el toolchain de Xcode.
   - *Solución*: Se instaló la versión estable `@react-native-async-storage/async-storage@2.2.0` (módulo nativo Objective-C++ `RNCAsyncStorage`), totalmente compatible con React Native macOS 0.79 y sin dependencias de frameworks Swift externos.

3. **Alineación del Deployment Target**:
   - Se ajustó `MACOSX_DEPLOYMENT_TARGET = 14.0` en `macos/Citas.xcodeproj/project.pbxproj` para coincidir con la plataforma macOS 14 declarada en el `Podfile`.
