# Walkthrough: Soporte macOS y Generación de DMG

## Resumen
Se integró soporte para **Expo Web** y **Electron** (`electron-builder`) para ejecutar la aplicación de **Citas Célebres** en macOS y empaquetarla como instalador `.dmg`.

## Cambios Realizados
- [electron/main.cjs](file:///Users/franciscogomezbarragan/Herd/citas/electron/main.cjs): Proceso principal de Electron que registra el protocolo `app://citas/` sirviendo el bundle estático de `dist-web/` de forma segura (sin problemas de rutas absolutas ni `localStorage` efímero).
- [package.json](file:///Users/franciscogomezbarragan/Herd/citas/package.json):
  - Dependencias agregadas: `react-dom`, `react-native-web`, `electron`, `electron-builder`.
  - Scripts agregados: `mac:build-web`, `mac:preview`, `mac:dmg`.
  - Configuración `build` de `electron-builder` para macOS (`target: ["dmg"]`, `identity: null` para compilación local sin certificado de firma).
- [.gitignore](file:///Users/franciscogomezbarragan/Herd/citas/.gitignore): Se agregó `dist-web/` a las rutas ignoradas.

## Verificación
- `npm run mac:dmg`: completado con código de salida `0`, generando `dist/Citas Célebres-1.0.0.dmg` y `dist/mac/Citas Célebres.app`.
- `npx tsc --noEmit`: sin errores de tipos.
